# Testing-phase seed

## Quick start

```bash
# Infra
docker compose up -d   # Postgres
cd backend && npx prisma migrate deploy

# Geo pack (already committed under prisma/data/; regenerate if needed)
npm run geo:build
# Requires Geonames dumps in /tmp — see scripts/build-geo-pack.mjs

# Seed World + ~196 NBs + major-city LBs + 20 clients/LB + 1B USDC World reserve
npm run db:seed:testing

# Verify + write Documentation/testing/verification-report.md
npm run db:verify:testing
```

Restart the API after seeding so memory banks sync from Prisma (`syncBanksFromPrisma` on boot), or call `POST /api/dev-admin/banks/sync` as Super Admin.

## Credentials

| Role | Login ID | Password |
|------|----------|----------|
| Super Admin | `admin@gmail.com` or `admin` | `i_am_admin` |
| National | country slug e.g. `bangladesh`, `north_korea` | same as ID |
| Local | `local_<country>_<city>` e.g. `local_bangladesh_dhaka` | same as ID |
| Client | `client_<country>_<city>_00001` … | same as User ID |

CSV exports (generated by seed):

- `Documentation/testing/credentials-national.csv`
- `Documentation/testing/credentials-local.csv`
- `Documentation/testing/credentials-clients.csv`

## Env knobs

| Variable | Default | Meaning |
|----------|---------|---------|
| `CLIENTS_PER_LOCAL` | `20` | Clients per local bank |
| `SKIP_CLIENTS` | `0` | Set `1` to seed institutions only |
| `BCRYPT_ROUNDS` | `4` | Faster hashes for bulk testing seed |

## Super Admin distribution

In `/dev-admin` Overview:

1. Confirm World reserve shows **1,000,000,000 USDC**
2. Allocate to any National / Local / Client via **Distribute World reserve**
3. API: `POST /api/dev-admin/allocate` `{ toType, toId, amount }`

National banks allocate only to their local banks; local banks lend to their clients — all start at **0** until World distributes.

## Scale

Approx: 196 countries · ~1,300+ local banks · ~20 clients each (~25k+ clients). Seed may take several minutes.
