Abstract

Crypto World Bank maps World → National → Local → Client lending onto an EVM ledger with programmable reserves, multi-entity products, and explainable ML risk support.

Keywords: Hierarchical DeFi · Smart contracts · XAI · Group lending

Flat DeFi ignores institutional hierarchy; development corridors stay opaque and slow. CWB encodes tiered capital and audit trails on-chain.

Methodology

Agile MVC (~16 weeks): Model = Solidity + PostgreSQL projections; View = React/Vite; Controller = Express.js + FastAPI. Hardhat tests gate merges (npm run test:contracts).

  • On-chain: Solidity 0.8.20 · WorldBankReserve · NationalBank · LocalBank · LoanController · AccessControl roles
  • Off-chain: Express API · Prisma/PostgreSQL (51-entity ERD; 16 core MVT) · FastAPI ML · Redis cache
  • Frontend: React + wallet signing · approver dashboards · optional MCP agent (17 banking tools)
  • Networks: Ethereum Sepolia (primary) · Polygon Amoy (fallback) · zkEVM Cardona (future)
  • Oracle: off-chain score → keccak256(s ‖ nonce) commit → reveal on LoanController (human still gates)

Key Design Choices

  • Stablecoin-first retail path (avoid ETH liability volatility)
  • L2 / testnet gas target ≈ $0.011 per loan lifecycle
  • Off-chain RF+IF+SHAP; humans approve; on-chain gates enforce
  • Single-chain settlement — multi-chain deferred (bridge risk)
  • Optional local MCP agent for demonstration UX

Conclusion

Hierarchical development-finance flows can live as auditable smart-contract state, with explainable ML assisting — not replacing — credit judgment. Next: Phase II–IV MVT loan E2E, oracle latency, and CWB-specific retrain.
